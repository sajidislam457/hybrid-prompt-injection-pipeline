## How credit is protected

| Mechanism | What it does |
|-----------|----------------|
| `LICENSE` (MIT) | Legal requirement to **keep the copyright notice** in copies |
| `NOTICE` + `AUTHORS` | Explicit human-readable credit that travels with the tree |
| `CITATION.cff` | Academic citation metadata (GitHub “Cite this repository”) |
| `.github/CODEOWNERS` | Marks `@arefin95f` as code owner on GitHub |
| **Git commit history** | GitHub **Contributors** graph is built from commit authors |

### Important concept (please read)

GitHub’s **Contributors** list is **not** created by a magic file.  
It is created from **git commits** whose author is you (`Shams-ul Arefin <arefin95f@gmail.com>`).

- If someone **forks** this repo (keeps history) → you remain a contributor.  
- If someone downloads a ZIP and **re-uploads as a new repo without your commits** → GitHub will **not** auto-list you as a contributor on *their* repo.  
  Your protection then is **LICENSE / NOTICE / AUTHORS / CITATION** — removing those is a **license violation** and academic misconduct, not something code can cryptographically prevent.

There is **no honest technical way** to force your avatar onto someone else’s empty GitHub repo after they strip history. What we *can* do is make credit **hard to “accidentally” lose** and **easy to prove** if they delete it.
